# Agents

This directory contains agent personas and role definitions.

## Purpose
- Define agent behavioral characteristics
- Document agent responsibilities and constraints
- Provide context for AI orchestration layer

## Rules
- No executable logic allowed here
- Only descriptive, human-readable documents
- Behavioral descriptions and role definitions only

## Format
Each agent definition should include:
- Agent name and purpose
- Scope of responsibilities
- Constraints and safety rules
- Example interactions or scenarios
